# خارطة طريق ARAB UNION

## المرحلة 1 — نموذج قابل للعب
- [x] مدينة أولية ثلاثية الأبعاد ومناطق أساسية.
- [x] حركة اللاعب والكاميرا وتحكم لمس.
- [x] مركبة أولية قابلة للقيادة.
- [x] تفاعلات محلية أولية للخشب والصيد.
- [x] حفظ محلي تجريبي.
- [ ] نماذج وأصول فنية أصلية بجودة إنتاجية.
- [ ] نظام تصادم وطرق وملاحة وواجهة إعدادات كاملة.

- [ ] Game Server موثوق، غرف، مزامنة مواقع، حضور وأصدقاء.
- [ ] دردشة مع ضوابط إساءة الاستخدام ومكافحة السبام.

## المرحلة 3 — الاقتصاد والمهن
- [ ] عمليات خادم ذرية للمحفظة والمعاملات والمكافآت.
- [ ] مخزون وموارد ووظائف ومهام ومتاجر.
- [ ] سباقات ومكافآت خاضعة للتحقق على الخادم.
- [ ] عقارات ومركبات وملكية موثقة.

## المرحلة 4 — الإدارة والإطلاق
- [ ] لوحة إدارة مع صلاحيات server-side وتدقيق لكل إجراء.
