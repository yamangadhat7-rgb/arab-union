# حالة تنفيذ اتحاد العرب

آخر تحديث: 2026-11-18

## موجود فعلياً
- مستودع GitHub مفعّل ويقبل الكتابة.
- مشروع واجهة Vite وThree.js.
- مشهد ثلاثي الأبعاد إجرائي مع مدينة أولية، دوار، أعلام رمزية، قصر، غابة، بحر ومبانٍ.
- حركة شخصية، تبديل كاميرا، تحكم لمس، مركبة أولية قابلة للقيادة.
- جمع خشب وصيد كتفاعلات محلية تجريبية.
- حفظ محلي على الجهاز عبر localStorage.
- قاعدة Supabase بحالة ACTIVE_HEALTHY والجداول الأساسية التالية: profiles, wallets, transactions, player_progress, vehicles, properties, admin_roles.
- RLS مفعّل على الجداول الأساسية، مع منع العميل من تعديل المحافظ والمعاملات والمركبات والعقارات وأدوار الإدارة مباشرة.

## غير مكتمل / لا يجوز وصفه بأنه جاهز
- واجهة تسجيل الحساب والدخول والخروج واستعادة كلمة المرور موصولة بـ Supabase Auth عبر البريد وكلمة المرور. عند إنشاء الحساب يرسل النموذج اسم اللاعب والدولة إلى trigger قاعدة البيانات، الذي ينشئ profile ومحفظة 500 وسجل البداية. بعد الدخول تُقرأ بيانات الملف والمحفظة من Supabase.
- لا يوجد اتصال لعب Multiplayer بين مستخدمين.
- لا يوجد Game Server authoritative.
- عمليات الاقتصاد والمخزون والعقارات لم تُنفذ كعمليات خادم متكاملة؛ الرصيد الأولي فقط ينشأ تلقائياً عند التسجيل.
- عناصر الخشب والسمك تحفظ محلياً فقط ولا تتزامن بين الأجهزة.
- تم تفعيل workers.dev للنطاق `arab-union.arab-union-world.workers.dev` ونشر Worker يخدم index وملفات JS/CSS من GitHub main. تفعيل النطاق تحقق عبر Cloudflare API، لكن لم يتسنّ إجراء اختبار متصفح خارجي مستقل من بيئة الأدوات.
- اجتاز GitHub Actions فحص صياغة JavaScript (`npm run check`) وبناء Vite (`npm run build`) بنجاح على commit `332be15c8fcc96354e331603b28a1f2f92acce9c`.

## ملاحظات الأمان المعروفة
- Supabase Security Advisor أظهر تحذيراً واحداً على public.is_admin() لأنها SECURITY DEFINER ويمكن للمستخدم المسجل استدعاؤها. الدالة تعيد فقط نتيجة فحص دور المستخدم الحالي، وتُستخدم في سياسة قراءة admin_roles لتجنب recursion. يجب مراجعتها قبل توسيع صلاحيات الإدارة.
- Performance Advisor أظهر ثلاثة فهارس غير مستخدمة حالياً؛ لا تحذفها قبل وجود حمل حقيقي وقياس الاستعلامات.
- لا يوجد حساب مدير مهيأ تلقائياً، ولا توجد أسرار في المستودع.
