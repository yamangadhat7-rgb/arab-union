# اتحاد العرب | ARAB UNION

مشروع لعبة عربية ثلاثية الأبعاد للمتصفح، مبني باستخدام **Three.js + Vite**. هذه النسخة هي **نموذج لعب أولي (Prototype)** وليست إصداراً نهائياً أو لعبة Multiplayer مكتملة.

## ما يعمل حالياً
- عالم ثلاثي الأبعاد قابل للاستكشاف: ساحة الاتحاد، دوار مركزي، أعلام رمزية، مبانٍ سكنية، قصر، أشجار وغابة وشاطئ.
- شخصية قابلة للتحريك باستخدام WASD أو عصا لمس افتراضية.
- كاميرا منظور ثالث وأول قابلة للتبديل، مع تدوير بالسحب.
- سيارة أولية يمكن ركوبها وقيادتها والنزول منها.
- تفاعلات محلية تجريبية لجمع الخشب والصيد.
- حفظ عناصر النموذج محلياً في متصفح الجهاز عبر localStorage.
- واجهة عربية RTL متجاوبة مع الهاتف والكمبيوتر.

## ما لم يُنفّذ بعد
- تسجيل دخول فعلي وربط ملفات اللاعبين بواجهة اللعبة.
- اقتصاد موثوق على الخادم؛ الرصيد الظاهر 500 د.أ تجريبي فقط، ولا يمثل أموالاً محفوظة في قاعدة البيانات.
- Multiplayer متزامن بين اللاعبين، غرف، مزامنة حركة أو دردشة.
- وظائف ومهام ومخازن ومتاجر وبنك وتحويلات مالية فعلية.
- شراء/بيع العقارات والمركبات، وواجهة إدارة آمنة.
- أصوات، نماذج فنية نهائية، تحريك شخصيات متقدم، تحسين شامل للأداء واختبارات الأجهزة.
- نشر إصدار إنتاجي موصولاً بالخدمات.

## التشغيل المحلي
يتطلب Node.js 22 أو إصداراً حديثاً متوافقاً.

```bash
npm install
npm run dev
```

لفحص صياغة JavaScript وبناء ملفات الإنتاج:

```bash
npm run check
npm run build
npm run preview
```
